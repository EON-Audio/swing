# Swing

**The Swing beta is closed. Swing is out.**

Thanks to everyone who installed the beta, broke it and wrote back.

The finished Swing, with updates through ReaPack, is at **[eonaudio.pro/swing](https://eonaudio.pro/swing)**.

If you ran the beta: your install keeps working and your songs open as before. When ReaPack syncs it will report an
error for the beta's address. That's expected. To stop it, untick "EON Studios — Swing 2" in
Extensions > ReaPack > Manage repositories. Untick it, don't Uninstall it: Uninstall deletes the files your songs use.
