# EON Step Sequencer — Preset Library Credits

These presets are original drum programming authored by EON. Substyles are grounded
in publicly documented genre conventions (BPM, swing, kick/snare/hat placement,
velocity dynamics) from production-education sources, and several are **inspired by**
the general aesthetic of influential producers. No preset is a transcription of any
specific recording, and producer names are used only to credit stylistic influence —
not to imply endorsement or affiliation.

## Style influences (descriptive preset names)
- **G-Funk** — West-Coast / G-funk tradition (Dr. Dre lineage)
- **Soul-Chop** — soul-sample chop hip-hop (Kanye West lineage)
- **Anthem** — big anthemic soul-hip-hop (Just Blaze lineage)
- **Minimal-Funk** — sparse, syncopated, spacey funk (The Neptunes lineage)
- **Melodic** (trap) — lush melodic trap (Black Metaphor lineage)
- **Neo-Soul / Boom-Bap swing** — the J Dilla / Questlove pocket
- **Nu Trap Swing** — EON / Quaz signature: New Jack Swing shuffle (Teddy Riley) on
  trap drums, with melodic R&B 808s (T-Pain) and a soulful hip-hop pocket (J. Cole) —
  "if Bruno Mars was a trap rapper."

## Reference sources
Genre conventions verified via Attack Magazine (Beat Dissected), Native Instruments,
MusicRadar, LANDR, Reason Studios, eMastered, uJam, Drumeo, and other production
tutorials. Swing/velocity values are idiomatic recipes, ear-calibrated to this engine.
